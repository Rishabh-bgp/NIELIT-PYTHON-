# NIELIT-PYTHON-

Reference material and capstone projects for the Python language, prepared for NIELIT work.

## Language reference

[python_mastery.ipynb](python_mastery.ipynb) covers the core language: the execution model, names and mutability, control flow, functions, collections, exceptions, files, objects, decorators, the standard library, and type hints. Theory sits above each example, and the code cells include captured interpreter output.

## Capstone projects

Each notebook is independent. It states the design, then runs a complete program with captured output.

| Notebook | Project |
| --- | --- |
| [Project_01_Safe_Expression_Calculator.ipynb](Project_01_Safe_Expression_Calculator.ipynb) | Recursive-descent calculator with memory, history, and division-by-zero handling |
| [Project_02_Tic_Tac_Toe.ipynb](Project_02_Tic_Tac_Toe.ipynb) | Tic-tac-toe against a minimax opponent |
| [Project_03_Hangman.ipynb](Project_03_Hangman.ipynb) | Hangman state machine with repeated-guess protection |
| [Project_04_Quiz_Master.ipynb](Project_04_Quiz_Master.ipynb) | Marked quiz with a fixed paper and a score report |
| [Project_05_Expense_Tracker.ipynb](Project_05_Expense_Tracker.ipynb) | Monthly ledger using `Decimal`, category totals, and budget alerts |

Restart the kernel and run from the top after editing a cell.
