# NIELIT-PYTHON-

Reference material for the Python language, prepared for NIELIT work.

## Notebook

[python_mastery.ipynb](python_mastery.ipynb) is a self-contained reference covering the core language:

- Execution model, names, binding, and mutability
- Scalars, operators, truthiness, and control flow
- Functions, scope, closures, and argument forms
- Strings, collections, comprehensions, iterators, and generators
- Exceptions, files, and context managers
- Classes, inheritance, properties, and dataclasses
- Decorators, the standard library, and type hints

Theory sits above each example. The code cells include captured interpreter output, so the notebook can be read without a kernel. Restart the kernel and run from the top if you edit a cell.
